= mermaid-svg-css-vars

Post-process Mermaid SVG: theme colors to CSS vars with fallbacks + webCompatibility normalization.

link:https://github.com/openshellorg/mermaid-svg-css-vars/issues[Report Bug] ·
link:https://github.com/openshellorg/mermaid-svg-css-vars/issues[Request Feature]

== About The Project

Intermediate library that post-processes *Mermaid-rendered SVG* so one prerendered diagram works under host light/dark themes, and embeds cleanly on the web.

Package: `@openshellorg/mermaid-svg-css-vars`

Mermaid derives theme colors with *khroma* from *concrete* color values — CSS custom properties cannot be used at render time. This package rewrites emitted SVG colors to `var(--mermaid-primaryColor, #resolvedFallback)` so the host theme can override without re-rendering.

== Installation

[source,bash]
----
pnpm add @openshellorg/mermaid-svg-css-vars
# until npm publish: pnpm add github:openshellorg/mermaid-svg-css-vars
----

== Usage

[source,ts]
----
import {
  rewriteMermaidSvgCssVars,
  normalizeMermaidSvgForWeb,
  prepareMermaidSvgForWeb,
} from '@openshellorg/mermaid-svg-css-vars';

const ready = prepareMermaidSvgForWeb(svg, {
  themeVariables,
  cssVariables: true,
  webCompatibility: true,
  prefix: '--mermaid-',
});
----

=== CLI

[source,bash]
----
mmdc -i diagram.mmd -o diagram.svg -c mermaid-config.json
mermaid-svg-css-vars diagram.svg -o diagram.web.svg --theme-vars theme.json
----

=== Host CSS example

[source,css]
----
:root {
  --mermaid-primaryColor: #ECECFF;
  --mermaid-primaryTextColor: #333;
}
[data-theme="dark"] {
  --mermaid-primaryColor: #2a2a4a;
  --mermaid-primaryTextColor: #eee;
}
----
